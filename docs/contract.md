# Контракт каталога ссылок

Авторская конфигурация `reference-catalog` содержит `namespace`, `imports`, `exports`, `publication`. Неизвестные поля отклоняются. Поля `home` и `projects` принадлежат `project-publish`; прежний режим автоматической составной сборки удалён.

`namespace` — локальное имя текущего самостоятельного проекта. При составной сборке его задаёт интеграция. `imports` сопоставляет локальные псевдонимы источникам JSON; обязательны `source`, `namespace`, `base-url`, необязательны `title`, `style`. `exports` сопоставляет собственные пространства спискам ID или `"*"`. `publication.title` — название публикации.

Результат `reference-catalog.json` содержит текущую схему `quarto-reference-catalog`, сведения о Quarto, необязательное название публикации и `targets`. Ключ цели имеет вид `namespace:id`. Цель хранит относительную страницу, HTML ID, подпись и номер; для Reveal — также ID слайда. Модель JSON определена в `schemas/catalog.schema.json`.

Самостоятельная сборка требует явного подключения фильтра и `entrypoints/post.ts`. Расширение не добавляет проектных обработчиков при установке. Проект составной публикации передаёт полный набор уже созданных HTML в адаптер `entrypoints/publication.ts`. Импорт в PDF не реализуется: QRC разрешает ссылки в веб-публикации; PDF-раздатка доступна по обычным ссылкам на файл.

Публичные поля определены в `domain/contract.ts`; единственный словарь стилей — `vocabulary/reference-styles.json`, его статические проекции для TypeScript, Lua и CUE создаёт `tools/generate-vocabulary.ts`; перечень типов целей Quarto — в `lua/constants.lua`. При пользовательских типах crossref фильтр дополняет встроенный словарь из штатных метаданных Quarto.
