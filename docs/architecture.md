# Архитектура QRC

* `domain` — модель каталога, ключи и стили, адресация, отбор экспорта; без запуска процессов и Quarto.
* `infrastructure` — чтение конфигурации, импорт JSON, HTML-адаптер, разрешение ссылок и запись каталога.
* `entrypoints/post.ts` — явная точка завершения самостоятельной сборки.
* `infrastructure/publish.ts` — явный API local/full для уже созданных outputs.
* `lua` — стандартные фильтры Quarto: ссылки и обнаружение целей; список типов находится в `constants.lua`.
* `browser` — раскрытие скрытых HTML-блоков и переход к фрагментам Reveal.

Автор явно подключает QRC в каждом native проекте. Самостоятельный post-hook
читает публичный список outputs Quarto и вызывает local. Опциональный
course-site вызывает full после успешных native процессов и размещения частей,
передавая текущие outputs, namespaces и индексы поиска. Метаданные и цепочки
фильтров остаются в авторском YAML; runtime overlay отсутствует.

Оба режима проверяют containment и существование каждого выбранного output,
без обхода retained HTML. Каждая выбранная страница разбирается один раз;
linker обновляет HTML и его дерево, а поиск использует это же дерево. Full
объединяет явные поисковые индексы с mount-префиксами и удаляет записи страниц,
которых нет в текущем наборе. Local сохраняет hidden probes для будущей полной
финализации, full удаляет их после строгого разрешения ссылок.

Необязательный `portal` объявляет фактическую root-страницу прямого caller.
Её namespace берётся из root-конфигурации, а не из пути или HTML. Caller
подтверждает успешность native процессов; QRC проверяет адреса готовых outputs.

QRC не определяет курсы, задания, оценивание, оформление, корневую страницу, PDF или политику публикации. Стили ссылок определяются единственным JSON-словарём в `vocabulary/reference-styles.json`. Из него создаются статические проекции TypeScript, Lua и CUE; проекции не редактируются вручную. TypeScript сохраняет точный литеральный тип стиля. `tests/boundaries.ts` сравнивает файлы с детерминированным результатом генерации, без разбора программного кода. Перечень типов целей Quarto используется только Lua и остаётся в `lua/constants.lua`.
